# KRSERVER
Self-hosted homelab server built with Ubuntu, Docker, Nginx, ASP.NET Core, monitoring, DNS filtering and media services.


A personal Ubuntu Server homelab built from an old laptop.

Hardware
- Intel Core i5-1035G1
- 8 GB RAM
- 256 GB SSD
- Ubuntu Server

Infrastructure
- Docker / Docker Compose
- Nginx
- SSH key authentication
- Pi-hole
- Jellyfin
- Uptime Kuma
- Beszel
- Portainer

Custom Development
- KRServer monitoring dashboard
- ASP.NET Core REST API
- Server CPU / RAM / disk / temperature monitoring

Networking
- Local network services
- DNS filtering
- Reverse proxy
- Network file access
